# HostelConnect

A web app for hostel students to report and claim laundry mix-ups.

## Features
- User authentication (Registration No + Password)
- Post laundry mix-up reports
- View only your hostel block's posts
- Auto-delete posts after 7 days
- Image upload via Cloudinary
- Mobile responsive

## Tech Stack
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Authentication:** Passport.js
- **Image Upload:** Cloudinary
- **Frontend:** EJS, Bootstrap 5
