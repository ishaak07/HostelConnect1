# HostelConnect 

A web app for hostel students to report and claim laundry mix-ups.

## ✨ Features
- 🔐 Secure authentication (Registration No + Password)
- 📦 Post laundry mix-up reports with images
- 🏢 View only your hostel block's posts
- 🤖 AI Description Generator (Groq + Llama 3)
- 💬 AI Chatbot Assistant — find your clothes instantly
- ⏳ Auto-delete posts after 5 days
- 👤 Profile page with your posts
- 📱 Mobile responsive

## 🛠️ Tech Stack
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Authentication:** Passport.js
- **Image Upload:** Cloudinary
- **AI:** Groq API (Llama 3.3)
- **Frontend:** EJS, Bootstrap 5
